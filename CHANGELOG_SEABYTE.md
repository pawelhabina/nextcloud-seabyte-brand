# SeaByte Cloud changelog

## 33.0.7-seabyte.1 — 2026-07-26

- Based the fork on Nextcloud Desktop `v33.0.7`.
- Added centralized, environment-overridable SeaByte OEM configuration.
- Added deterministic application, tray, Explorer, Finder and installer asset
  generation from the supplied SeaByte SVG artwork.
- Branded the shared UI, account wizard, About dialog, notifications, default
  server and default sync folder, with Polish and English OEM translations.
- Added isolated Windows executable, AppUserModelID, registry, WiX MSI,
  UpgradeCode and shell-overlay integration.
- Added isolated macOS app/extension bundle IDs, App Group, entitlements, URL
  alias and File Provider/Finder configuration.
- Disabled the official update channel and documented a future private feed.
- Added Windows/macOS release scripts, GitHub Actions, signing hooks, SHA-256
  manifests and 239 static branding assertions.
